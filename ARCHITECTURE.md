# LOVE CHESS — structured edition

Эта версия сохраняет текущую рабочую логику LOVE CHESS, но раскладывает код по функциональным модулям.

- `js/core/state.js` — общее состояние, seed, ключ localStorage и общие настройки.
- `js/core/data.js` — сохранение данных и пересборка истории завершённых турниров.
- `js/auth/auth.js` — вход игрока и работа с аккаунтами.
- `js/players/players.js` — игроки, ники и поиск.
- `js/pairing/pairing.js` — Swiss / Dutch-style pairing.
- `js/tournament/tournament.js` — турниры, туры, результаты, редактирование и рейтинг.
- `js/pages/home.js` — главная, расписание, рейтинг и страницы «О нас».
- `js/avatars/avatars.js` — аватары и статусы.
- `js/profile/profile.js` — «Мой профиль», награды и права редактирования профиля.
- `js/organizer/organizer.js` — кабинет организатора.
- `js/clock/clock.js` — шахматные часы.
- `js/router.js` — маршрутизация.
- `js/bootstrap.js` — запуск приложения после загрузки всех модулей.

Важно: это всё ещё статическая версия, поэтому данные хранятся в `localStorage`. Разделение файлов улучшает поддержку кода, но само по себе не создаёт серверную общую базу данных.

## Server-side foundation

Для production-версии добавлен серверный контур:

- `server/index.js` — HTTP API и безопасная раздача статических файлов;
- `server/schema.sql` — PostgreSQL-схема пользователей, профилей и сессий;
- `server/security.js` — проверка данных, salted scrypt-хэши паролей и непрозрачные токены сессии;
- `server/db.js` — подключение к БД и транзакции;
- `privacy-policy.md` — шаблон политики конфиденциальности.

До развёртывания нужно создать PostgreSQL, задать переменные окружения из `.env.example` и заполнить реквизиты оператора данных в политике. Данные из старого `localStorage` не переносятся автоматически: для них потребуется отдельная миграция, согласованная с организатором.
