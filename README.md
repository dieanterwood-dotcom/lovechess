# LOVE CHESS

Сайт клуба и турнирный сервис. Статическая часть находится в корне, серверное API — в `server/`.

## Локальный запуск

1. Установите Node.js 22+ и PostgreSQL 16+.
2. Создайте базу данных `lovechess` и примените схему:

   ```bash
   psql "$DATABASE_URL" -f server/schema.sql
   ```

3. Скопируйте `.env.example` в `.env`, задайте корректный `DATABASE_URL`.
4. Установите зависимости и запустите сайт:

   ```bash
   pnpm install
   pnpm start
   ```

Сайт будет доступен на `http://localhost:3000`.

## Первый организатор

После применения схемы создайте единственный начальный аккаунт организатора из защищённого терминала:

```bash
pnpm create-organizer admin-login 'сложный-длинный-пароль' 'Ник организатора'
```

В коде нет встроенного пароля организатора. Не публикуйте эту команду с настоящим паролем и не добавляйте пароль в GitHub.

## Безопасность

- Пароли сохраняются только как salted scrypt-хэши.
- Сессия хранится в `HttpOnly`, `SameSite=Lax`, а в production — `Secure` cookie.
- В репозиторий нельзя добавлять `.env`, пароли, токены или строку доступа к БД.
- Перед публичным запуском заполните реквизиты и контакты в `privacy-policy.md`.
